# B站直播间竖屏极简版

一款 B 站直播间**竖屏自适应重排**油猴脚本（Tampermonkey）。窄窗/竖屏时把直播间重排为手机 App 式的纵向布局，宽屏时自动还原 B 站原版 UI。

## 功能

- **自适应布局**：窗口宽 ≤ 高（竖屏/窄窗）自动切为纵向布局——主播信息栏 / 播放器 / 礼物栏 / 房间观众·大航海 / 弹幕区（占最大空间）/ 弹幕输入栏；窗口宽 > 高（横屏）自动还原原版 UI。带迟滞防抖与每秒自检，拖拽窗口实时切换，跨显示器移动也能自愈
- **弹幕修复**：滚轮滚动接管（原生滚轮失效的修复）+ 新消息自动跟随到底部（往上翻看历史时暂停跟随，滚回底部自动恢复）
- **视频满宽**：消除左右黑边，解除 B 站 980px 固定宽度限制——极窄窗口、浏览器缩放、竖屏副屏均正常
- **屏蔽干扰**："TA的动态/主播公告"等异步加载内容不再挤掉弹幕区；隐藏顶部导航、页脚、悬浮件
- **禁用网页全屏入口**（控制栏按钮 + 双击手势），避免误触毁掉竖屏布局

## 安装

1. 安装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（支持 Edge / Chrome / Firefox）
2. 点击安装：[bilibili-live-portrait.user.js](https://raw.githubusercontent.com/sfqy211/bilibili-live-portrait/main/bilibili-live-portrait.user.js)
3. 打开任意 [B站直播间](https://live.bilibili.com/) 即可自动生效

## 使用说明

| 窗口状态 | 表现 |
|---|---|
| 宽 ≤ 高（竖屏/窄窗） | 竖屏重排布局 |
| 宽 > 高（横屏，如 16:9） | 自动刷新一次页面，还原 B 站原版 UI |
| 再拖回竖屏 | 自动切回竖屏布局（无需刷新） |

- 竖屏 → 横屏的还原采用整页刷新以保证原版 UI 完整，直播流重连约 1~2 秒
- 刷新后弹幕从当前时间点开始显示（B 站直播本身不回放历史弹幕）

## 已知限制

- 网页全屏入口被禁用（进入会破坏竖屏布局）；如需全屏观看，可拖宽窗口切回原版 UI 再操作
- B 站页面改版可能导致脚本失效（此时脚本会静默放弃，不影响原版页面），欢迎提 [issue](https://github.com/sfqy211/bilibili-live-portrait/issues)
- 与其他 B 站增强类脚本/扩展（Bilibili-Evolved、各类弹幕助手等）同时使用可能相互干扰，建议二选一
- 实测环境：Edge + Tampermonkey（Windows，竖屏副屏）；Chrome 理论兼容，Firefox 未测试

## 隐私

脚本**不发出任何网络请求、不收集任何数据**，全部逻辑在本地页面内完成。
